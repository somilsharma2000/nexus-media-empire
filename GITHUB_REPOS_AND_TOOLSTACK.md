## 2. Core Internal Tech Stack

* **Frontend Framework:** Next.js 14 (App Router, Incremental Static Regeneration, React Server Components).
* **Styling & Motion:** Tailwind CSS + Framer Motion (Neumorphic Dark Theme, dynamic glow effects).
* **Icons:** Lucide React (Clean, tree-shaken SVG glyphs).
* **Authentication:** NextAuth v5 (Biometric & Credential sessions with Bcrypt protection).
* **AI Inference:** NVIDIA NIM APIs / OpenAI API (Meta Llama-3.3-70B, DeepSeek-R1, GPT-4o-mini).
* **Storage Layer:** Atomic File-Based JSON Data Layer (`/data/*.json`) with zero external database dependencies.
* **Cron & Scheduler:** Vercel Cron (`vercel.json`) / Local Chrono Engine / Background Daemons.
* **Notification Bridge:** Grammy Telegram Bot API (`lib/telegram.ts`).
